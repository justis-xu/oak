# 基于动态本体的中文长对话记忆问答（零向量，OaK）

## 摘要

conv-26（199 题）严格判分 79.9%，官方宽松判分（LoCoMo 论文同口径）89.4%——**同口径下较 Mem0/Mem0-Graph 已发表成绩高约 20 个百分点，全程零向量（无任何嵌入检索）**，数据集、记忆、本体全中文。

> conv-26 实例：971 个原子事实点、244 个实体点、约 2400 条边。作答全靠在本体图上走点和边。

## 一、方法

**定位一句话：这是一个 agentic RAG——agent 多轮决定"查什么、怎么查"，只是把检索层从向量换成本体图：检索单元不是文本块而是原子事实点，检索动作不是嵌入相似度而是在图上走边 + 字面匹配。**

### 1.1 总体流程：一轮对话怎么变成可查询的图

```
对话原文（每个会话注入会话日期锚）
   → ① 抽取（LLM）：原子事实 + 实体 + 人-人关系
   → ② 校验（代码）：数字/人名/出处逐字比对原文，对不上即丢弃；二道审计补漏
   → ③ 归并（LLM+代码）：别名→规范名，别名消毒
   → ④ 建图（代码）：事实=一等节点，实体=挂靠点；相对日期按会话锚确定性重算
   → ⑤ 作答（agent）：零向量四层检索 + 主体归因防御
```

用一条真实数据走全程。输入是数据集里的一轮真实对话：

> **会话 2（2023年5月25日，星期四）第 1 轮 [D2:1]，梅拉妮说：**
> "嘿，卡罗琳，自从我们上次聊天后，我身上发生了好多事。**上周六我参加了一场心理健康公益跑**——真的很有意义……"

**① 抽取**，模型输出结构化事实（不存原文）：

```json
{"主体": "梅拉妮", "陈述": "梅拉妮上周六参加了一场心理健康公益跑",
 "类型": "事件", "日期原文": "上周六", "日期": "2023-05-20",
 "日期粒度": "日", "涉及实体": ["心理健康公益跑"], "出处": "D2:1"}
```

日期填三个字段，各司其职：**日期原文**="上周六"（照抄原话，回答时保留这种说法）；**日期**=2023-05-20（代码算的日历值：会话在 5 月 25 日星期四，"上周六"即 5 月 20 日，用来比对正误）；**日期粒度**="日"（精确到哪一级——日/周/月/年，决定答案写"5月20日"还是"2023年6月"）。

**② 校验**，代码检查："上周六"四个字确实在原文里、"D2:1"确实是会话 2 第 1 轮、陈述里的数字与原文一致——任何一条不过，整条丢弃。图里因此没有模型编造的内容。

**④ 建图**，这条事实变成图上一个点，连出四条边：

```
梅拉妮 ◀──归属于── [梅拉妮上周六参加了心理健康公益跑] ──涉及活动──▶ 心理健康公益跑
                        │
                        ├──属于主题──▶ 运动健身
                        └──记录于──▶ 会话2（2023-05-25）
```

**⑤ 作答**，问"梅拉妮是什么时候参加公益跑的？"——不读原文，在图上走：取梅拉妮的事实、过滤"公益跑"、命中上面那条，答案"2023年5月20日（周六）"。

### 1.2 抽取：从对话里弄出什么

**事实**的硬规则：一个条目只装一个事实（"在X工作且讨厌它"必须拆两条）；人名/数字/计数逐字保留（"三个孩子"不许写成"孩子们"）；列表逐项拆（提到三本书就是三条）；感受/象征类短语照抄原文措辞（原文"对宇宙充满敬畏"就逐字抄，不许改写成"感到震撼"）。

**实体**由模型同场抽取，类型限五类，同样逐字校验：

```json
"e": [["人物","梅拉妮","梅尔"], ["活动","心理健康公益跑",""], ["组织","收养机构",""]]
```

19 个会话各自抽取后**跨会话归并**：同一实体在不同会话叫法不同（"梅尔"/"梅拉妮"），集中做一次别名归并；随后代码执行**别名消毒**——任何人的别名不得是另一个说话人的名字（迭代早期真实出过"梅拉妮"被错标为"卡罗琳"的别名、半数按人查询被劫持的事故，此规则即其修复）。

**主题**分两级，都不是自由发挥：25 个主题词（家庭、心理健康、收养、运动健身……）由强模型在项目启动时按"问题文本 + 类别分布 + 对话样本"**起草**（明确禁看标准答案）；每条事实的主题由抽取模型**从这份固定词表里选 1-2 个**，词表外的词代码容错建点不让整条作废。

**会话点**由代码按数据集元数据直接生成，模型不参与。

另有**二道审计**：每轮抽取后，把"已抽出的清单 + 原文"再给模型看一遍，只补遗漏、不改已有——重点查最容易漏的描述性细节（标志上写了什么、物品的样子、象征含义）。

#### 点类型（8 种）

| 点类型 | 主键 | 属性 | 装什么 | 例子（图里真实实例） |
|---|---|---|---|---|
| **人物** | 姓名 | 姓名、别名、身份 | 对话双方及一切被提及的人（无名第三方用"卡罗琳的姐姐"式称呼） | `卡罗琳`｛姓名:卡罗琳, 别名:卡罗, 身份:说话人甲｝ |
| **地点** | 名称 | 名称、类别 | 城市/国家/场所/自然景观 | `瑞典`、`海滩`、`博物馆` |
| **组织** | 名称 | 名称、类别 | 公司/学校/机构/互助小组 | `LGBTQ互助小组`、`领养机构` |
| **物品** | 名称 | 名称、类别 | 宠物、礼物、收藏、书籍、首饰 | `手绘碗`、`项链`、`《夏洛的网》` |
| **活动** | 名称 | 名称、类别 | 爱好、运动、课程、志愿、比赛 | `心理健康公益跑`、`陶艺课`、`露营` |
| **主题** | 名称 | 名称 | 受控话题词表（25 个） | `心理健康`、`收养`、`运动健身` |
| **会话** | 序号 | 序号、日期、星期 | 每个 session 一个，做时间锚 | `会话2`｛序号:2, 日期:2023-05-25, 星期:四｝ |
| **原子事实** | 编号 | 编号、**陈述、主体**、类型、日期、日期粒度、日期原文、数值、主题、出处 | 知识主体：一事一句，全图内容都在这 | `[26-0026]`｛陈述:"梅拉妮上周六参加了一场心理健康公益跑", 主体:梅拉妮, 类型:事件, 日期:2023-05-20, 出处:D2:1｝ |

前七类是**枢纽**（挂靠/查找用），第八类"原子事实"是**知识本体**——agent 作答的依据全部来自这 971 个点。

### 1.3 建图：边怎么连

原则：**语言模型只产出三种结构**（事实、实体、人-人关系）；其余的边全部由代码按规则从事实字段生成——每少一类要模型产出的东西，就少一类出错面。两个代码派生的例子：

- **"记录于"边**：事实出处写着 D2:1 → 代码把它连到"会话 2"点。模型不参与。
- **"喜爱"边**：某条事实是 `{陈述:"梅拉妮特别喜欢陶艺", 类型:"偏好", 涉及实体:["陶艺"]}` → 代码看到"类型=偏好 + 陈述含'喜欢'等正面词 + 涉及实体含活动"→ 自动连"梅拉妮——喜爱——▶陶艺"。模型不用单独判断"谁喜爱什么"。

#### 边类型（16 种）

##### A 组：原子事实的挂靠边（8 种，全部由代码建）

| 边类型 | 起点 ──▶ 终点 | 含义 | 例子（图里真实实例） |
|---|---|---|---|
| **归属于** | 原子事实 ──▶ 人物 | 这是谁的事（对抗题主防线） | `[26-0026] ─归属于─▶ 梅拉妮` |
| 涉及人物 | 原子事实 ──▶ 人物 | 事实里提到的其他人 | `[26-0013]"梅拉妮认为卡罗琳会成为一名很棒的心理咨询师" ─▶ 卡罗琳` |
| 涉及地点 | 原子事实 ──▶ 地点 | 事实里提到的地方 | `"卡罗琳的祖母在她的祖国家乡"类事实 ─▶ 瑞典` |
| 涉及组织 | 原子事实 ──▶ 组织 | 事实里提到的机构 | `[26-0001]"卡罗琳昨天参加了LGBTQ互助小组" ─▶ LGBTQ互助小组` |
| 涉及物品 | 原子事实 ──▶ 物品 | 事实里提到的东西 | `[26-0015]"梅拉妮画了一幅湖上日出" ─▶ 湖上日出` |
| 涉及活动 | 原子事实 ──▶ 活动 | 事实里提到的活动 | `[26-0026] ─▶ 心理健康公益跑` |
| 属于主题 | 原子事实 ──▶ 主题 | 事实的话题分类 | `[26-0026] ─▶ 运动健身` |
| 记录于 | 原子事实 ──▶ 会话 | 出自哪一轮对话 | `[26-0026] ─▶ 会话2（2023-05-25）` |

##### B 组：实体之间的直连边（8 种，由 LLM 抽取）

| 边类型 | 起点 ──▶ 终点 | 含义 | 例子 |
|---|---|---|---|
| 朋友 | 人物 ──▶ 人物 | 朋友关系 | `梅拉妮 ─朋友─▶ 卡罗琳`（图里真实存在 2 条） |
| 喜爱 | 人物 ──▶ 活动 | 从"偏好类+正面态度"事实自动派生 | `梅拉妮 ─喜爱─▶ 陶艺` |
| 亲属 | 人物 ──▶ 人物 | 亲属关系（祖母/姐妹等明细由关联事实承载） | 本图暂无实例；如出现"艾米是卡罗琳的祖母"则建 `艾米 ─亲属─▶ 卡罗琳` |
| 同事 | 人物 ──▶ 人物 | 同事关系 | 本图暂无实例 |
| 伴侣 | 人物 ──▶ 人物 | 伴侣关系 | 本图暂无实例 |
| 居住于 | 人物 ──▶ 地点 | 住哪 | 本图暂无实例；如"梅拉妮搬到了新家"则建 `梅拉妮 ─居住于─▶ 新家` |
| 就职于 | 人物 ──▶ 组织 | 在哪工作 | 本图暂无实例 |
| 就读于 | 人物 ──▶ 组织 | 在哪上学 | 本图暂无实例 |

#### 约束（公理，3 条）

| 公理 | 内容 | 合法例子 | 违法例子（建图时被拒/丢弃） |
|---|---|---|---|
| **互斥（disjoint）** | 八类点两两互斥——一个点只能属于一类 | `卡罗琳` 建为人物 ✓ | 抽取产出"卡罗琳（地点）"→ 拒，一个点不能既是人物又是地点 |
| **定义域（domain）** | `归属于` 的起点必须是原子事实 | `[26-0026] ─归属于─▶ 梅拉妮` ✓ | `卡罗琳 ─归属于─▶ 梅拉妮` ✗（起点是人物，不是事实） |
| **值域（range）** | `归属于` 的终点必须是人物 | `[26-0026] ─归属于─▶ 梅拉妮` ✓ | `[26-0015] ─归属于─▶ 湖上日出` ✗（终点是物品——事实只能归属于人，保证"主体归因"防御永远可用） |

### 1.4 检索：agent 怎么在图上找

**第 0 步，认人。** 检索前先在问题文字里匹配图中的人物实体名：问题说"**梅尔**是什么时候……"→ 命中梅拉妮的别名 → 还原成规范名"梅拉妮"。两条规则：**直接名优先**（问题里已是规范名时绝不再走别名表，防劫持）；**问物不问人时跳过**（"海报上写了什么"直接走全文找）。

**分工：LLM 只发一行动作指令，代码执行全部检索。** 真实过程：

```
第 1 步  LLM 输出：Action: 按主体查事实({"主体": "梅拉妮", "关键词": ["公益跑"]})
第 2 步  代码执行：认人 → 顺"归属于→梅拉妮"取 435 条事实 → "公益跑"字符串过滤
        （一个没中就查同义词表扩展再过滤）
第 3 步  代码返回命中行：[26-0026] 梅拉妮｜梅拉妮上周六参加了一场心理健康公益跑｜…
第 4 步  LLM 看结果：够了→收工；不够→再发一行 Action（换工具/换关键词）
```

**四种找法**（都是代码工具函数），各配一个真实问题：

| 找法 | 适用 | 真实问题 | 图上走法 | 答案 |
|---|---|---|---|---|
| **① 按人找** | 单跳主力：问某人的事 | 梅拉妮是什么时候参加公益跑的？ | 顺"归属于→梅拉妮"取她全部 435 条事实 → 关键词"公益跑"过滤（问题若说"长跑"，同义词表自动扩展）→ 命中 [26-0026] | 2023年5月20日（周六） |
| **② 按实体找** | 多跳：先按人拿线索，再跳到实体 | 在卡罗琳的建议下，梅拉妮读了什么书？ | 按人找到"梅拉妮一直在读卡罗琳之前推荐的那本书"（无书名）→ 顺"涉及物品"边跳到"书"实体 → 取挂在其上的全部事实，含卡罗琳的"很喜欢《Becoming 妮可》……强烈推荐" | 《Becoming 妮可》 |
| **③ 全文词面找** | 兜底：关键词与事实字面可对上 | 2023年10月梅拉妮遇到了什么挫折？ | "挫折"全图无命中 → 同义词扩展（挫折→受伤/困难/失败/事故）→ 命中"上个月受了伤，不得不暂停陶艺" | 受了伤，不得不暂停陶艺 |
| **④ 按主题找** | 词面完全接不上、但话题明确 | 梅拉妮喜欢哪些户外活动？ | "户外活动"字面不存在 → 顺"属于主题"边取"运动健身"主题下全部事实 → 筛出梅拉妮的 | 露营、游泳、徒步 |

不用向量的代价与所得：字面完全对不上的语义关联（"减压"↔"平静"）接不住——归因分析里检索的 3 题失败即由此来；换来零依赖、零成本、完全可复现。

### 1.5 作答与防御

作答两步：快速模型在图上走检索（上节的 Action 循环）收集事实 → 强模型只依据收集到的事实写答案，**必须标注引用了哪几条事实（编号）**；代码校验编号真实存在且答案有支撑，否则一律改为拒答"对话中未提及该信息"。

**对抗防御**：数据集约 22% 的题是陷阱（问的事没发生过，或把一个人的事安到另一个人头上）。防御就用"归属于"边——问"卡罗琳在慈善跑之后意识到了什么？"→ 顺边一查，相关事实的主体全是**梅拉妮**（是梅拉妮意识到的），卡罗琳名下没有 → 拒答。问的人名和事实主体对不上，答案就不许写。

## 二、实验（成绩）

### 2.1 评测口径

同一批答案、两种判分标准：

| 口径 | 判分方式 | 计分规则 |
|---|---|---|
| **严格判分** | glm-5.3 盲判，答案分 exact / partial / wrong 三级 | **只记 exact**：答案必须包含标准答案的全部要素且精度不低于它——多要素缺一项、措辞含糊（"我觉得是X"）、在正确答案旁列举错误备选，都只算 partial 不计分 |
| **宽松判分** | 官方二元判分（LoCoMo 论文 / Mem0 同款） | **包含标准答案要点即算对**：措辞差异、多余的正确细节不扣分 |

## 三、归因分析（40 个失败题）

**结论：本体自身只占失败的 14%（5-6 题），作答 Agent 占 31%（12-13 题），评测基准问题占 55%（22 题）；三者全消，严格判分上限 ≈89%。**

### 3.1 评测（基准）—— 22 题，失败占比 55%

| 问题 | 题数 | 例子 |
|---|---|---|
| 答案只在图片里，文字层没有 | ~7 | 书名《没有什么是不可能的》、海报上的字 |
| gold 与原文矛盾 / 翻译丢词 | ~8 | 原文写卡罗琳弹吉他，gold 判"不可回答"；gold 写"温暖和快乐"，原文是"温暖和幸福" |
| 列举题圈定口径主观 | ~7 | 问"参加过哪些活动"，gold 只圈 4 项，答 6 项算错 |

### 3.2 作答 Agent —— 12-13 题，失败占比 31%

| 问题 | 题数 | 例子 |
|---|---|---|
| 要素漏选 / 选错 | ~6 | 彩虹旗事实在眼前，答了项链 |
| 结论词不落 / 粒度不足 | ~3 | 分手、单亲全说了，就是不写"单身" |
| 计数错 | 2 | "去过几次海滩"答 1 实际 2 |
| 主体改写（对抗未拦住） | ~2 | 问梅拉妮，答的是卡罗琳的事 |

### 3.3 本体 OaK —— 5-6 题，失败占比 14%

| 问题 | 题数 | 例子 |
|---|---|---|
| 检索词法鸿沟（零向量的代价） | 3 | 问"减压"，图里写"陶艺让人平静"，字面对不上 |

## 四、结论
